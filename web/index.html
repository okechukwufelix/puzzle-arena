How it works

  1. Hold an Agent ID. Agent ID is claimed inside the Binance App (Wallet > homepage banner > Agent ID). One Agent ID per person.
  2. Read the puzzle. A new round opens every 12 hours and runs for 12 hours. The answer is always a single number.
  3. Prove it is yours. Type your own handle once. The site computes your Agent ID from it and checks on-chain that it belongs to your connected wallet — before the solve button is enabled.
  4. Solve on-chain. Your answer is checked against the round's answer hash in the contract. A correct answer mints a free Solve NFT to your wallet. Free to play — you only pay network gas.
  5. Build a streak. Solve on consecutive UTC days and your streak grows. Streaks belong to your Agent ID, not to any one wallet.

One entry per Agent ID per round, enforced by the contract. The Solve NFT is a collectible with no monetary value, and no prizes or returns are promised.

FAQ

What does it cost to play?
Nothing but network gas. The Solve NFT itself is free — free to play, you only pay network gas. The value sent with the transaction is always 0 BNB.
What is the Solve NFT worth?
It is a collectible with no monetary value. No prizes or returns are promised.
Do I need an Agent ID?
Yes. Only Agent ID holders can play. If your wallet holds no Agent ID, solving is disabled and the site tells you how to claim one in the Binance App (Wallet > homepage banner > Agent ID).
Why do I type my handle?
Your Agent ID is derived from your handle on-chain. The site computes it in your browser and verifies on-chain that it belongs to your connected wallet. Only your own handle is ever entered or shown — the site never looks up other people's handles.
Can I solve a round twice?
No. One entry per Agent ID per round, enforced by the contract.
What happens if my answer is wrong?
The transaction reverts and nothing is minted. You only pay gas for the attempt, so check the puzzle and your answer before confirming.
What can the contract owner do?
Only two things: schedule a new puzzle round (createRound — answer hash plus time window) and transfer or renounce ownership (standard Ownable). There is no withdraw function, no pause, no freeze, no token seizure, no fee, and no payable entry point. The contract cannot move your funds.
Which wallet do I use?
Your own injected wallet — Binance Wallet or MetaMask — on BNB Smart Chain (chain ID 56). There is no QR code login, no server session, and no backend. You see and confirm every transaction yourself in your own wallet.
